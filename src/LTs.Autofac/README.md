# LTs.Autofac

## Introduction
Extensions for Autofac to simplify its use.

This library includes:
- LTs.Autofac.DependencyInjection.Resources
  - KeyTypeManipulationResources
  - ServiceProviderExtensionsResources
- LTs.Autofac.DependencyInjection
  - AutofacServiceProvider
  - AutofacServiceProviderFactory
- LTs.Autofac.Extensions
  - AutofacPopulateExtensions.Populate()
  - AutofacRegisterExtensions.RegisterType()
  - AutofacRegistrationExtensions.Populate()
  - AutofacRegisterExtensions.RegisterGeneric()
  - ServiceProviderExtensions.GetAutofacRoot()
